# Hello EdgeOne

A dependency-free Hello World website. Open index.html directly to preview.

## Deploy from Git

1. Import this repository into EdgeOne Makers and select the main branch.
2. Choose the Other/static framework preset.
3. Root directory: ./
4. Build command: leave empty (no build required).
5. Output directory: ./
6. Deploy.

All interaction runs in the browser. No backend, secrets, dependencies, or environment variables are required.
